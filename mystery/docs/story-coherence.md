# 故事核对与修订 · 2026-10-31

本轮核对了游戏的十二页开场、全部可搜集物证与生成证词、五名NPC可回答的事实、主线判定和五条人物支线。原版依据是本机《羽生夜谈（6人）》复盘第1—4页，涉及旧案、双生身份、当夜行凶和鬼怪解释。以下内容含完整谜底。

原问题主要出在单人改编时省掉了人物自己的叙述，却保留了复盘结论。玩家可以在只拿到四项线索时结案，随后一下子得知人物身世、旧案责任和支线选择，缺少中间的问询过程。本轮补上这些环节，沿用毒针先致死、宫司随后刺伤并焚烧身体、惠美下茶在后的主线。

## 当夜顺序

1. 加藤最后离开厅堂去空屋放烛。石川尾随，以戒指毒针杀害哥哥，将身体扶成坐姿。
2. 石川摘下面具，以哥哥的样子返回厅堂，随后陪惠美回房。
3. 宫司检查空屋，认出仇人，未查验生死便刺向胸口；随后清扫、搬走身体，在花园焚烧遗体与祭服。
4. 石川等惠美睡下后离房，准备移尸。惠美随后醒来，去花园挖根，将根汁放入杯中。
5. 小仓看见铜炉火光，待人离开后去偏殿；石川寻找失踪的身体至此，两人交手，小仓用发簪刺伤他。
6. 加藤以亡魂状态从花园回房，喝下惠美准备的茶。石川后来在房前看见“哥哥”，逃回自己的客房服药。
7. 小仓在大殿、江一郎在膳所分别遭遇异象并昏迷，翌晨却在客房醒来。

第4—6步有并行行动，原材料没有可靠的精确钟点，本轮只使用能够互相约束的先后，不补造具体时刻。

## 保留的未解事项

原版复盘明确把昏迷后的经过留给续篇。本轮没有擅自指定搬运者，结案页会留下这条待查记录。小仓兄长的去向、秘宝的最终位置、组织及其他旧案责任，也不会因解决昨夜命案而自动查明。人物可承认自己的已知行为，未知部分继续保留。

已经保存的旧对话、支线收尾和结案文字属于玩家历史，本轮不覆写。后续生成使用新事实与新判定；旧档原有线索、行动点和扣分继续沿用。

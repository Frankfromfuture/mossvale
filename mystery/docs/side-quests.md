# 人物支线

五条任务围绕现有人物动机和线索编写，收尾为单人版改编。手记新增“支线”页，人物札记显示步骤和进度。后续步骤按顺序揭示，收尾正文只在完成后下发。

| 人物 | 支线 | 最后需要核实的内容 |
| --- | --- | --- |
| 宫崎正诚 | 记忆中的一家人 | 家人物件、惠美的童年回忆、神社旧册、人形师记载及人偶骨片；将相关证词和记载交给宫司核对。 |
| 江一郎 | 找回缺失的过去 | 用木牌、戒指、面具分别唤起三段记忆。 |
| 石川纪田 | 未说完的那一夜 | 核实身份、取得昨夜自述，并完成主线最终推断。 |
| 加藤太郎 | 未清的旧账 | 对照收购事故、浅野线索、大火与身份，向加藤出示合同、旧报纸与浅野线索，取得旧案供述；其余事故继续查证。 |
| 加藤惠美 | 由她决定的去路 | 核对家人记忆、身份、茶水经历，完成主线后让她说明去留。 |

条件齐备后，人物札记底部出现“当面收尾”。必须与本人在同一地点，正在被盘问时先处理当前问题。收尾计作一次交谈，调查中消耗1行动点；沿用结案后停止计分和扣行动点的规则。重复操作直接返回已保存结果。支线没有额外评分，也不阻挡主线结案。

旧档直接从既有线索、出示记录和本人实际听到的公开证据计算进度；没有在场听见的证据不算已经向该人物说明。首次收尾时才写入 `sideQuests.completed`。收尾台词进入交谈记录及实际听众的听闻，本人的后续对话会承接这次交代。私下收尾保留私下范围。

结案页展示五人的当前结果，未完成者继续显示下一步。结案后补完，再重读结局即可看到更新后的汇总。

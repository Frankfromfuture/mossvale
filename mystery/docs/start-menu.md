# 开始菜单与角色解锁

2026-10-31 后续更新：当前剧本及人物已更名，菜单视觉与选角滚动已调整，见 [最新说明](menu-art-and-names.md)。下文保留首版验收时的称呼。

每次打开页面先显示开始菜单，三个入口为“剧本选择”“继续进度”“设置”。剧本列表目前只有《羽生夜谈》。选择剧本后再选主角；继续进度会接续已有调查，开场口述未完成时继续当前口述，不扣额外行动点。

首次只有小仓信子可选。选角卡移除身份介绍、经历、玩法标签和难度，只显示头像、姓名以及开始／继续文字或解锁分数。锁定卡不可点击，服务端也拒绝直接请求锁定角色。开始菜单接口不返回故事页、线索、笔记或角色私密经历。

| 主角 | 解锁条件 |
| --- | --- |
| 小仓信子 | 初始可选 |
| 江一郎 | 结案调查分数达到 60 |
| 加藤惠美 | 结案调查分数达到 70 |
| 宫崎正诚 | 结案调查分数达到 80 |
| 加藤太郎 | 结案调查分数达到 88 |
| 石川纪田 | 结案调查分数达到 95 |

门槛按记忆、保密事项和身份处理的难度递增。60 与 70 分为第一次结案留出容错；80 分以上要求更谨慎地调查和交流，95 分保留给复杂视角。用同一访客所有已结案角色中的最高分计算，不累计多局分数，调查中的基础分不参与解锁。

最高成绩随存档保存，重开前先保留已取得的成绩。旧小仓进度可直接继续；此前试玩过但未达到门槛的其他角色存档继续保留，入口锁定，达到分数后恢复。锁定角色的旧档同样不能通过状态、动作或语音入口绕过限制。继续进度优先当前可用角色，其次接续已有的可用角色。

本轮修改 `server/role-saves.mjs`、`server/main.mjs`、`src/app.mjs`、`src/investigation.css`。沿用六角色存档结构，新增最高结案成绩字段。

验证：三项规则测试覆盖初始锁定、每个门槛前后一分、重开与低分后资格保留、旧档接续及锁定旧档。真实隔离 HTTP 验证未达标和伪造分数拒绝、旧档备份、重开后解锁及访客隔离。桌面 1280×900、手机 390×844 验证菜单三入口、设置返回、单剧本、六张简洁选角卡、小仓开局与继续；旧档手记及已用 87 行动点保持，页面错误零。截图最初早于头像图集加载，等待资源完成后核对了六张头像。

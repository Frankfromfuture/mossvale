# 阅读中的词条跳转

对话、历史记录、故事册、人物说明、调查记录和场景气泡使用同一套虚线链接。人名沿用人物札记；已取得的物件、证词和事件打开对应线索卡，同名物件有多张卡时先列出供选择。

地点和其他名词打开纸页词条，显示简短释义、点击处的原文，以及当前角色已经取得的相关线索和事件。未取得的物件可以查看它在原文中的提及，词条不补入未发现的内容。词库不读取作者用的案件真相文件。

资料可以连续跳转，返回、关闭和 Escape 都逐层回到来源，保留原页、滚动位置、焦点和对话草稿。输入框及已有操作按钮保持原来的操作；生成文本仍按纯文字显示。

通用词汇在 `src/reference-terms.mjs`，物件别称在 `src/clue-links.mjs`；当前角色的线索标题和所在地点物件名会自动加入匹配。新增剧本中的专名需补入词库。

本轮仅本地完成。一次 Web 构建，复用 4331；1280×900 对话与人物说明、390×844 故事册及多层返回通过，页面错误零。验收使用内存存档和隔离接口，无模型调用；记录见 `qa/reference-links-v1/verification.json`。

# 对话推进调查（0.15.0）

《第7号嫌疑人》的关键经过现在可以从人物嘴里问出来。初次询问得到一段说法，继续问来源、时间或遗漏之处，实际回答才作为口供收入手记。若第一句话已经问到了具体细节，可以直接讲清，无须为了凑轮次重复提问。开场向陈信问来路、向李察核对失联；旧案询问六人；遇袭后询问目击与离席；获救后找调查者核对资料，再当面对质。玩家也能直接向人物说出阶段判断，保留“证据不足”的推进方式。

身份、袭击、玉的去向和终章追问各有材料条件。两份材料摆好后，玩家仍要提出问题。人物先回应矛盾，下一次追问才交代已被证据约束的隐瞒；错误材料和提前猜中不会自动换来承认。终章的独立核查也可向调查者提出，由报告补齐证据。票选、搜证、密码和运输复原仍由玩家操作。

`server/suspect7/inquiries.mjs` 管理话题、调查条件、追问进度和来源线索。DeepSeek先按语义识别当前问题，再由人物表达本轮允许说的内容；两次输出都经过服务端校验。原话摘录须出自玩家输入，置信度低于0.8不推进。人物回答必须引用本轮事实；有效问答、材料出示、实际听众和进度一起提交，失败不写入，重试不重复调用或记账。判定的最近结果只留在服务端。

比对页沿用共用纸页。左、右各放一件物证或一张口供，下面的材料架支持点选与拖放；人物头像用于选择谈话对象。“拿去问”只准备可编辑的问题，回到交谈镜头后由玩家发送。手机保持左右并排，底部操作可见；查看原文后保留桌面选择；换材料时保留滚动位置。物件使用现有手绘图集，实测裁切集中于 `shared/suspect7/object-regions.mjs`，SVG按矩形裁切，排除相邻图块。

旧存档在当前章节继续沿用原条件，之后的章节进入问询流程。旧口供、成绩、旁注和路线均保留；查看存档不会写入迁移，首次实际操作才记录兼容章节。第一部的对话与行动规则保持。验证夹具和记录位于 `qa/dialogue-investigation-v1/`。

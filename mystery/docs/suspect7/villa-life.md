# 别墅日常活动（0.14.0，本地）

客厅增加茶台、书刊桌、棋盘、低书架、收音机、落地灯、盆栽和沙发靠垫。调查者进入客厅时，三位当前已登场的人物暂时过来休息；其余人留在餐厅或案情室。离开客厅后，众人回到原来的公共讨论区。这个安排只表示当前休息位置，不补写案发当天的行动。

客厅有喝水、翻书、摆棋和照看盆栽四类双人活动。案情室增加饮水柜、便笺板、文件架、纸笔和资料托盘，对应饮水、书写、整理便笺和归拢文具。两人起身走到物件旁，互相接话、使用物件，然后回座。桌上纸张和文件夹只是陈设，新增闲话不提供案件事实。搜证仍点击原有实体线索，正式公开材料仍在餐厅或案情室进行。

物件模型和活动站位共用 `shared/suspect7/activities.mjs`。第二部继续使用共用 `TownScene`、人物动作和 `SceneSocial`，第一部规则保持。案情室缩短会议桌并收拢座位纵向间距，给十一人起身和绕行留出空间。客厅交谈按界面标注保留双方听众，换房后丢弃旧地点的待播活动。

定向检查覆盖两处八类活动的行走、使用与回座，以及门口、座椅和原线索的通路；隔离浏览器检查桌面、390×844手机和第一部回归。证据保存在本地 `qa/villa-life-v1/`，截图在根目录 `output/playwright/villa-life-v1/`。本轮未调用真实模型或语音，未部署云端。

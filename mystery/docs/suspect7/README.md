# 《第7号嫌疑人》接入说明

本地版本 0.12.0。第二部通过 `server/scripts.mjs` 注册，第一部保留原有调查规则。内容依据用户提供的剧本、主持人本与两套线索整理，作者事实表见 [facts.md](facts.md)，逐条正文与页码见 [facts.json](facts.json)。这两份文件包含剧透，不进入网页资源。

玩家先以安迪进入一份供述，获救后改以吴全核对案件。其余五条路线在首次结案后开放，分数不设门槛。六条路线各自存档，换角保留同一条路线的物证、旁注和历史；前一角色未公开的独白不会进入新调查者的 AI 上下文。

六章依次覆盖出口与来电、两年前的劫案、投票、密室探索、供述核查和最终对质。推进只看调查节点，思考时间与网络等待不改变案发时序。玩家可以提前怀疑陈信，也可以把第五章判断保留为证据不足。第二部没有行动点、随机盘问、重复提问扣分或搜证礼貌处罚。

场景沿用《雾灯未眠》中央建筑的手绘材质、墙体剖视、连续行走和人物表现，重新布置为一层。餐厅与客厅居中，西侧安排客房、厨房、活动室和仓库，东侧安排教堂、书房、休息室与后侧储藏室，车库和温泉接在后侧。调查阶段将活动室改作临时案情室，现场仍可回访。十九处实体空间分章开放；活动室与案情室共用一处，因此有二十个地点编号。地图按实际比例显示已知房间与门，三维场景中的物件保留实体点击，物件列表提供等效入口。

这是空间改编。旧案、身份真相、手机改时和作案窗口保持原设定；上下楼供述改为进出东廊。东廊与客厅、餐厅之间是实墙，通向前厅的唯一公共出口经过休息室门前，支撑两份黑影证词的冲突。测量比较储藏室的室内北墙与建筑外缘，原来的垂直坡道改为平直检修通道，出口在池边。搬运需推送，复原步骤据此修改。改编条目保留原始来源页码，并注明空间变更。原始事实表继续记录原文，不作为改编后的建筑平面。

密室在密码开启前，通道在检查前，均不下发几何、门或物件位置。通道两端的指纹门禁在第四章保持封闭，警方接管后才允许行走。原房间编号和角色存档保留，旧档的活动室位置在调查阶段映射到临时案情室；玩家笔记、分数和选择保持。

首版包含45项物证／核查材料、34份可引用的原话，十一人的人物造型和头像。原作34条线索被拆分或合并成操作条目，新增材料带“改编新增”标记。普通复盘保留为可撤回的阶段推论，隐藏版作为结案依据。精确的定时拨号分钟、烧车遗体身份、司机死亡的行为人仍保留未定状态。

两通来电采用改编的固定字幕分镜与可选 Qwen 朗读，暂停、逐段翻阅和回看均可用。现场电话、脚步、柜子闷响、教堂关门和暖室声为本地合成短音，并有相应文字线索。原始两段MP4没有作为正式演出直接发布；它们的音轨尚未独立逐句转写。本版固定演出依据已核读的角色本文字改编，不宣称原片音画已完成逐句验收。

调查评价为100分：旧案40、主案40、证据连接及排除20。提示与修正猜测不扣分，直接揭示答案另记。章节时长是设计目标，2—3小时尚未经过真实玩家计时验证。

## 存档与连接

新版格式为 `scripts-v2`，按访客、剧本、路线存储。旧 `six-roles-v1` 和更早单角色存档只在内存映射；首次写入前生成同名 `.before-scripts-v2` 备份。原角色槽位、成绩和记录放入 `books.hanyu`。第二部使用 `books.suspect7`。

`POST /api/script` 接受 `scriptId` 与当前 `slotToken`；角色、剧本、视角切换均更新会话令牌。同名李察路线从供述转调查也换令牌。旧令牌动作返回409，旧语音连接随令牌变化关闭。聊天生成期间的切换由已有访客锁阻止；经校验的完整回复才写入存档。

第二部动作继续使用 `/api/action`。双证据追问与承认条件由服务端确定。AI只接收当前人物可说的事实、实际听众范围内的旧话及玩家出示材料；事实编号校验与提前泄露检查失败时，不保存回复。语义检索复用已有记忆选择器，原话始终与核实结果分开。

## 验证边界

规则检查使用内存夹具；HTTP及浏览器使用临时数据目录。正式 `.data` 只做只读兼容检查与前后哈希、时间戳比对。真实模型和语音效果不在本轮验收中，云端保持现有版本。定向规则入口为 `node --test qa/suspect7.test.mjs`；完整动作路径位于 `qa/suspect7-v1/journey.mjs`，验收证据位于同目录和 `output/playwright/suspect7-v1/`。

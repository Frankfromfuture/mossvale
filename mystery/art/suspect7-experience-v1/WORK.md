# 第二部共用体验改造 · 0.13.0

两部剧本现使用同一个应用、场景、人物控制与阅读界面。第二部按故事提供空间和操作内容，原独立应用与场景实现已移除。

本轮检查了第一部的应用状态、场景构建、连续寻路、落座与闲谈、交谈特写、表情、物件、地图、手记、人物资料、词条链接、纸页内框、故事册、幕间、菜单、语音和音效实现；同时核对其调查、开场、许可、计分、个人目标、NPC记忆、存档和服务端路由。共用实现继续承担相同操作，案件差异由服务端投影与内容配置提供。

正式美术为22张 imagegen 图像，清单与哈希见 assets.json。生成提示词见同目录各 JSON 和文本记录。十一位人物分别设置发型、五官、服装、配饰与动作倾向；年龄不明的角色外观属于美术改编。物件图集覆盖45项材料，灰色地毯与打火机用于安迪视角。六章漫画、终局、封面和固定来电画面已接入共用纸页。

场景为二十处单层实体空间，活动室与案情室共用同一位置，合计二十一个地点编号。屋舍分布于餐厅、客厅和两侧通路，内庭有围墙与锁住的院门。固定种子植被、河流、路灯、石径和屋顶使用共用渲染。餐厅与案情室均留有独立座位、起身和私谈通道。

验收使用临时 HTTP 数据目录与内存夹具。安迪—吴全全程、六路线换角、实际听众与隐藏信息、第一部接续、全部开放房间与实体搜证点通路、桌面及手机均已检查。漫画与来电朗读连接使用模拟音频验收；13段真实 Qwen 样音单独保存，接口成功不作为听感结论。未调用真实对话模型，也未部署云端。

本轮正式 Web 构建后，产物检查发现换角时原餐厅桌椅被移除，补齐固定陈设后追加一次前端构建，共两次；服务端仅重启一次。本地正式数据基线为17项，完整证据见 mystery/qa/suspect7-experience-v1/，浏览器截图见 output/playwright/suspect7-experience-v1/。

# 游戏化界面验收

2026-10-11，Cocos Creator 3.8.8。独立隐藏浏览器，本机 4319 服务。

改动集中在 `TownHud.ts`、`Mossvale.ts` 和 `StreetWorld.ts` 的界面、镜头与连续地面；桌面竖屏预览去掉外围阴影。原有寻路、居民人格、记忆和服务端规则继续使用。

| 本轮检查 | 结果 |
| --- | --- |
| 轻点道路 | 落点脚印出现，玩家移动，镜头跟随；靠近林夏后显示名字 |
| 林夏长按 750ms | 五枚图标围绕触点展开；松手保留，选择聊聊打开气泡 |
| 气泡阅读 | 轻点切到下一段；角色与场景始终可见，输入默认收起 |
| 回复及恢复 | 人为阻断本标签页的 `/api/interact` 一次；提示单独显示，原句“今天想在咖啡馆坐坐。”恢复完整。解除阻断后重发成功，收到居民回应 |
| 手记 | 空地花瓣菜单可打开，左右箭头在近况与已有记忆间翻页；标题和正文无重叠 |
| 构建 | TypeScript 检查、Cocos Web Mobile 与微信小游戏构建通过，入口场景包含在输出内 |

试玩发现纸页标题与正文靠得太近，调整后重新构建两端；只复验受影响的手记和翻页。最终浏览器日志没有警告或错误。临时网络阻断已解除。

Web 输出 19 个文件、2,526,489 字节；微信输出 24 个文件、2,188,562 字节，方向为 portrait。已更新可导入的微信工程压缩包，未进行微信手机验收。

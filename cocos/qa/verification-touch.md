# 简化触控验收

2026-10-11，Cocos Creator 3.8.8，后台浏览器验证。

| 场景 | 结果 |
| --- | --- |
| 轻点道路 | 显示落点标记，人物沿路前往，镜头跟随；抵达后标记消失 |
| 长按空地 750ms | 显示行走、手记、全景、休息菜单；松手后菜单保留，没有执行行走 |
| 菜单选择 | 从空地菜单打开单列手记，居民经历保留 |
| 长按林夏 750ms | 显示聊天、帮忙、邀请、赠礼、共同回忆；菜单内无模型信息 |
| 共同回忆 | 从菜单选择后，人物走近林夏并显示她的已有经历 |
| 轻点居民 | 直接打开交谈，不先弹出选项菜单 |
| 中文输入 | 输入并提交“早上好，今天有什么打算？”后，林夏正常回应自己的安排；未显示模型名称 |
| 构建 | TypeScript 检查、Cocos Web、Cocos 微信及早期 2D Vite 构建通过 |

Cocos Web 为 19 个文件、2,516,786 字节；微信输出为 24 个文件、2,178,822 字节，方向仍为 portrait。微信手机尚未实测，AppID 和测试后端的前置条件沿用上轮记录。

“使劲按”按跨设备可用的长按实现：550ms 触发，移动超过 12 个设计像素取消，不依赖屏幕压力。此阈值已在浏览器鼠标按住的方式下验证，手机触控与键盘遮挡仍待微信真机确认。最终浏览器日志未观察到错误或警告。

本轮移除方向盘、居民快捷栏和底部操作栏，交谈面板收起额外动作。3D、早期 2D 与原生微信界面的模型名称、调用次数和技术状态文案已清理。后端模型调用、记忆和预算逻辑保持原样。

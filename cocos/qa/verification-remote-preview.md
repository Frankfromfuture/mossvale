# 阿里云远程试玩验收

2026-10-11。Cocos Web Mobile 正式构建一次，TypeScript 检查通过。网页资源部署到 Brizo 既有上海 ECS，使用独立容器及 `/mossvale/` 路径；后端保留在 Mac，经 SSH 加密转发。

隐藏浏览器通过公网 HTTPS 邀请链接进入，随后跳转到不含凭证的游戏地址。竖屏场景正确加载；点居民后角色走近，长按展开互动，选择“帮个忙”后居民给出模型回应。刷新页面后重新打开该居民回忆，仍显示“你花时间帮林夏完成了手边的事。”

未携带邀请凭证访问返回 401。本机游戏根路径返回 200；Brizo 原官网返回 200，原同步路径继续拒绝不支持的 GET（405）。代理新增路由通过 Nginx 配置检查，并以热重载生效。

首次安装脚本遇到服务器 Python 3.6 的 subprocess 参数差异；修正兼容性后安装成功，首次失败发生在写入代理配置之前。没有重建或重启 Brizo 现有业务容器。

此版本依赖 Mac 保持开机联网；本次只完成远程网页测试，未完成全部后端上云、微信小游戏上传或手机真机验收。

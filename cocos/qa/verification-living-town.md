# 小镇场景与自主生活验证

2026-10-11，Web Mobile 已更新至原阿里云试玩入口。

## 本轮变化

十二位居民、九处连通活动地点。增加集市摊位、花圃、广场木琴、过桥果园和河畔休息道具。场景默认动作、加入居民活动、口袋收集及对应记忆均已接入。居民使用服务端路径与活动状态，替换原先只在地点附近循环走动的表现。

修改集中在 `server/life.mjs`、现有引擎与路由接入、四份 Cocos 脚本，以及共用的 `town-layout.json`。早期 2D 行动逻辑保留。旧三人存档载入时先保存升级前备份，补入其余居民；人格 Markdown 文件仍未直接参与运行。

## 验证结果

- TypeScript 检查通过，Cocos Web 正式构建通过。首轮画面检查发现果园被远景树遮挡、花圃花朵低于土面；合并修正后重新构建了交付版本。
- 内存中的旧三人存档升级保留原信任和记忆。九个地点两两可达；推进 180 个游戏分钟，记录 47 次完成活动、17 次相遇，覆盖全部九处地点，居民坐标均在可行走区域。
- 雨天继续推进后，居民均到达室内地点；重复点击采摘被冷却限制拒绝。存档序列化再载入保留口袋与升级标记。
- 独立后台浏览器按手机竖屏运行，玩家沿 44 个路径点过桥到达果园，成功采摘一颗桃子；随后与阿澈在河畔一起看水，信任由 30 增至 33。模型回答能提及这次共同活动。回复额外提到“风吹着舒服”，该细节没有事件证据，仍只保存为转述，这是现有生成约束的局限。
- 重载并重启服务后，桃子和阿澈的共同经历仍在。玩家继续到花园完成浇水，只有当时在附近的苏晴收到对应经历。
- 后台桌面 Chromium、390×844 布局的十二人场景采样约 60.0 fps，帧间隔 P95 为 18.2 ms；108 个采样帧。一次较长 CDP 采样超时，改用短窗口取得结果。这不是安卓真机性能结论。
- 原公网 HTTPS 入口加载到十二位居民和九处地点；读取时七位居民正在行走，未发现页面错误日志。

原始调度结果见 [living-town-state.json](living-town-state.json)。截图：[果园交谈](living-town-orchard.png)、[花园](living-town-garden.png)、[远程版本](living-town-remote.png)。

## 部署与边界

静态资源先上传，入口文件最后替换；服务器保留 `index-before-living-town.html` 备份。远端没有 rsync，使用归档上传至临时目录后，由现有免密权限安装到原发布目录。未改变 Brizo 官网、代理授权规则或模型凭据。

日常行动与邻里短句当前按规则执行，玩家交谈继续使用原模型；未增加持续的自主模型调用。房屋内部、背包食用、物品赠送、乐器声音和微信真机验收尚未实现。多个居民靠得很近时，名字仍可能重叠。

云端提供网页和素材，本机 Mac 提供游戏后端及存档，远程试玩继续依赖 Mac 开机联网。

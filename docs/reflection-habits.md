# 居民反思与个人习惯

2026-10-13，已接入本机 2D 网格版。沿用 DeepSeek API、现有服务器和各小镇存档。十一位常住村民实际参与生活；叶小满的档案也补齐了习惯，但继续留在历史档案中。

参考《Generative Agents: Interactive Simulacra of Human Behavior》（[论文](https://arxiv.org/abs/2304.03442)）中“经历、反思、计划”的联系：先留下实际经历，再形成可修订的看法，并把看法放回之后的决策。这里保留了原有经济和行动规则，没有照搬论文的完整代理系统。

## 经历怎样变成看法

每位村民只整理自己参与并已记录的事件，取上次整理之后最近四十条。至少积累三条事实、重要度合计达到十五，才进入反思；单个对象还需至少两条相关事实。地点必须实际出现过，人物必须与本人共同参与事件。别人说过的话继续标为转述，旧反思也不会再次充当事实。

DeepSeek 结合本人的性格、价值观、经历和已有看法，提出一至三条暂定印象。服务器核对对象和全部来源，再保存印象、引用的原事件、旧版本与新版本。任何一条来源不合格，整次结果退回；重复回复不会重复增添影响。

对地点的印象影响空闲时想去哪里，对人的印象影响是否愿意与附近邻居来往，也会进入本人的对话上下文。影响有上限，并随时间减弱。新的经历可以改变旧看法；正在做的工作、接受过的邀请、睡眠和吃饭仍按真实状态处理。反思本身不改基础性格、信任数值、钱款或承诺。

原事件和动态印象保存在该小镇的 JSON 存档，分别位于事件库、本人记忆及 `resident.reflection`。涉及私事的看法不会进入邻居闲谈上下文。旧存档首次载入前保存 `.before-reflection-v1`，原有经历保留。

每人每个游戏日最多反思一次，两次至少间隔四个游戏小时。反思请求串行进行，每个小镇每天最多使用十六次 API 调用，以 UTC 日期计数，并计入原有自主活动额度，保留玩家交谈额度。离线期间只补算实际生活事件，返回后再整理近期经历。超时、额度不足或结果无效时，保存中性的经历整理，不凭空增加好恶。

## 每个人的一天

十二份 `soul.md` 的 `daily_life.economy_routine` 分别定义起床、睡觉、用餐、工作时间与时长、连续工作后的休息间隔、工作方式、喜恶和三项具体习惯。每项习惯包含可发生的时段、地点、活动时长、原因及雨天去处。现有性格中的安静需求和社交精力也参与空闲活动选择。

## 画面与查看方式

视野里的村民头顶显示黑底线框小气泡，框内图标对应实际任务，如读书、饮茶、种植、打扫、修理、护理或睡觉。行走时增加箭头，同时保留目的活动图标。交谈、邻居发言或打开面板时收起相应气泡。图形只在任务变化时重画，位置随人物更新；点击气泡可选中村民。

右上角“村民”可查看个人作息、喜恶、做事方式与今天的习惯。“经历形成的看法”中能继续打开原始依据和看法变化记录。

## 已实现与后续范围

已实现的是有事件依据的反思、可修订印象、个人习惯、对去处和相处意愿的影响，以及可查看的来源记录。`memory.md` 仍是设计模板，运行记忆保存在存档中。向量检索、完整分层计划和随经历自动学习新习惯尚未实现；本轮完善的固定习惯由人物档案维护。

定向验收记录见 `cocos-2d/qa/reflection-acceptance.json`：一天内十一位村民均完成各自三项习惯；一组有来源的印象改变了后续去处；连续推进与分段补算一致，酒店仍有真实入住收入，钱款守恒。另检查了来源拒绝、私事隔离、重复回复、修订记录和保存后恢复。验收使用独立小镇。

一次正式 Cocos Web 构建已通过。真实 DeepSeek 调用用许知远的既有事件生成了三条印象，全部通过来源核对，记录在 `cocos-2d/qa/reflection-deepseek.json`。后台 Chromium 检查了 1280×800、390×844 画面、村民资料、印象依据和气泡点击；记录见 `cocos-2d/qa/reflection-ui.json`，无浏览器错误。这是桌面后台验证，未测真实手机帧率。

本轮只更新本机 2D。原远程 3D 网页的聊天和存档仍通过加密通道连接 Mac，需要 Mac 开机联网。

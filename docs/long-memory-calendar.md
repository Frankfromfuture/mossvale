# 长期记忆、日程与约定

2026-10-14，接入本机 2D。网格和像素版共用服务器行为；新增资料内容沿用原来的画框、字体和滚动组件。两个独立 3D 工程及远程入口未更新。

## 记忆怎样保存和查找

旧存档的事件、记忆正文、账本和人物资料保留。升级前保存 `.before-town-mind-v1`。新经历的正文留在事件库，个人记忆保存事件编号、类型、时间、重要度和本人依据；读取时从原事件取得正文，客户端仍能显示原文。记忆、印象、日程和约定分别保存。

长期检索使用本机的中文词组、英文词及少量主题索引，结合相关程度、重要度和时间选取经历。索引仅在内存中，追加经历时增量更新，重启后重新建立。玩家对话和自主台词每次最多取七至八条、总文字约 2200 字；Jev 决策最多取五条、约 900 字。未新增嵌入模型或检索 API 调用，也未修改 DeepSeek 温度和输出预算。

检索先检查事件是否属于本人，再检查直接及间接引用的来源。邻居闲谈和 Jev 公共上下文排除秘密及由秘密形成的记忆；私人交谈可以使用本人的私有经历。保存一份正文不代表其他人物有权读取。

索引和输入长度上限解决的是查找与模型上下文增长。真实历史仍然累积，旧档中的重复正文也保留，因此 JSON 存档总量仍会增长。冷历史分片、向量语义检索、自动摘要及 `memory.md` 写回尚未实现；本轮不会通过删掉原始经历来缩小存档。

## 当天安排

`resident.calendar` 保存当天的用餐、工作窗口、个人习惯和睡眠安排，以及正在执行的任务。开始实际任务或交谈延长任务时，只推迟受影响、尚未完成的灵活事项；超过习惯窗口的显示为今天顺延。完成的事项、固定作息和原有经济任务不被改写。资料中能看到安排状态和最近的调整原因。

每个新游戏日按既有人物作息生成当天安排，最近调整原因最多十二条。实际完成的经历仍由原来的事件结算记录，计划本身不当作完成事实，也不发工资、物品或关系奖励。

## 约定怎样落地

当前支持带明确日期、24 小时时间和公共地点的见面邀请，例如“明天19:00在公园一起散步”，也支持“今天”“后天”“第N天”。“改天一起”及尚未支持的时间表达仍保留为普通对话。

服务器先检查营业、天气、工作、吃饭、睡眠、既有约定和时间范围；居民通过既有台词请求明确接受，服务器再复核后建立约定。玩家提出邀请即表达自己的意愿；邻居相遇则由第一人的实际台词提出邀请，第二人收到原话并接受后建立。草稿、失败请求和一句含糊的提议都不生成约定，未增加单独的模型请求。

约定保存在 `world.commitments`，包含参与者、时间、地点、来源和状态。居民保留当前任务，随后提前留出赴约时间并按原寻路执行；双方在约定时段实际到场才记录兑现。超时记录未能赴约，明确取消则停止这项尚未完成的赴约任务。正在履行其他经济任务时不取消工作或退改工资。约定本身不改变账本、稳定人格和关系值。

玩家可以在与对应居民交谈时明确说“取消这次见面约定”；仅有一项双方有效约定时执行，否定、假设或含糊的取消不执行。亦提供已鉴权的 `/api/commitment-action` 取消接口。多项约定时通过编号区分。酒店原有邀请接入同一状态追踪，保留原来的做客、茶点和反馈规则；旧邀请沿用原记录，不补造接受事件。

活动约定最多三十二项，近期结束的状态最多四十项；接受与结果事件继续保存在完整历史里。村民资料显示时间、地点和状态，生活记录显示实际结果。

## 20% 空闲行动随机性

只有至少两项接近本人偏好的合理候选、精力至少 35、饥饿低于 75 时，才以 20% 概率选择另一项空闲活动。候选检查营业、天气、私宅归属、通路和下一项责任时间；必要时缩短活动时长。随机分支在 Jev 请求前决定，因此不会再请求模型解释一个已经随机选出的结果；其余分支沿用 Jev 或人格规则。

工作、吃饭、睡眠、进行中的任务、个人习惯和有效约定优先。随机性不修改性格、印象、信任或金额。随机状态单独持久保存，不消耗原来的游客经济随机序列；保存后恢复及连续、分段推进使用同一序列。20% 是每次合格选择的概率，短期比例会浮动。

## 本轮验证

`cocos-2d/qa/town-mind-check.json` 记录隔离内存小镇的定向验收：四千余条个人记忆中找回较早的具体经历；本人和邻居上下文权限检查；保存恢复；局部日程调整；两位村民实际寻路赴约；取消、失约和重复处理；随机候选与序列持久性；连续一天与分段推进一致，资金守恒，酒店实际入住收入保留。

一万次合格候选抽样中，随机分支触发 1957 次，观察比例为 19.57%。这次验收覆盖服务器行为与存档规则，真实模型的人物台词、长期表现及手机真机效果尚未验收。

本机 2D 启动脚本启用 `MOSSVALE_TOWN_MIND=1`；原 3D 启动脚本不启用。正式 Cocos Web 构建和本机服务重启各一次。

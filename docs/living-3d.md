# 苔溪镇 · 立体生活

2026-10-13，本机新增 `cocos-town3d/`。它把当前 LPC 2D 的物件、居民生活和村长经营接到斜视角 3D 画面，原来的几个版本继续保留。

## 入口与存档

| 版本 | 本机地址 | 工程 | 存档 |

4322 已在本机启动，4319、4321 的原服务保持运行。4317 保留源码、构建和原启动方式，本轮没有启动。新 3D 是独立小镇，不会搬走或覆盖 2D 进度；各版本的浏览器会话也分开。新界面的地图页提供版本入口。

## 已接入的玩法

| 内容 | 新 3D 的处理 |
| --- | --- |
| 人物与日常生活 | 村长、11 位常住村民和临时游客；沿用独立人格、作息、工作、习惯与自主行动 |
| 聊天与记忆 | 沿用 DeepSeek 对话、实际经历、印象修订、承诺和个人记录；Jev 决策及规则接管信息可在记录中查看 |
| 酒店与经济 | 两间基础客房、待布置客房、游客入住、杂活、家具购买、仓库、税款、账户、逐笔账本与离线结算 |
| 地图与物件 | 同一份地图和 29 类物件定义；1m 逻辑格、门、家具、植物、杯书等小物件拥有原来的状态与动作 |
| 家具布置 | 搬动、90° 旋转、收进仓库、承载面摆放；桌面物件跟随家具，碰撞与通路随服务器结果更新 |
| 操作 | 轻点行走、轻点人物交谈、长按目标菜单、拖动行走、双指平移与捏合、触控板手势、加减缩放 |
| 查阅 | 经济、村民资料、生活记录、Jev 依据与耗时、印象来源和修订、地图与素材署名 |

这些功能使用原有服务器实现。模型只提出建议，行动、钱款、时间和存档仍由服务器检查和执行。客户端只替换呈现与坐标换算，没有另建一套经济或记忆规则。原 2D 尚未实现的完整 `memory.md` 写回、向量检索与自动学习新习惯，也没有在新 3D 中宣称完成。

`server/main.mjs` 仅增加可选 Cookie 名称；`server/objects.mjs` 仅增加可选物件目录路径。未设置新环境变量时，旧模式继续使用原来的默认值。新服务仍经原启动器读取已授权模型配置，密钥不会进入客户端或仓库。

## 画面与屋顶

使用固定约 35° 俯角的透视镜头，竖屏布局，带静止区的平滑跟随。房屋、家具和植物统一采用苔绿、奶油色与暖木色；按钮、气泡和账本使用相同配色。当前是一套简洁的低多边形美术，尚未制作高细节建筑贴图和完整生活动作动画。

咖啡馆、书屋、工坊、酒店的屋顶根据实际墙体分组生成。主角进入建筑范围后，整片屋顶隐藏；离开后恢复，并留少量边界余量防止门口闪烁。屋顶挡住镜头到主角的视线时也隐藏。前景墙与门框降为矮墙，近处挡人的树冠暂时收起，通行规则保持原样。

杯子、书和盆栽放在真实承载面高度，点击使用 3D 射线。打开的门按门框和门板的实际范围命中，门洞可以穿过和点选。

## 人物素材

采用 [Kenney — Animated Characters Protagonists](https://kenney.nl/assets/animated-characters-protagonists) 的 CC0 人类模型，统一使用同一骨架、三种服装贴图及不同帽色。保留作者原包、许可和来源清单，转换为 glTF，合并待机与行走动画，并由待机姿态派生坐姿。此版未使用任天堂角色模型。

- 原始文件：`vendor/kenney-3d/protagonists.zip` 及同名解压目录。
- 运行素材：`cocos-town3d/assets/resources/people/`，约 396 KB，包含编辑器元数据。
- 转换步骤：`cocos-town3d/scripts/prepare-characters.py`。
- 许可与散列：`cocos-town3d/legal/sources.json`、`Kenney-CC0.txt`。
- 游戏内：地图 →「3D 素材与作者署名」。

## 手机性能处理

目标为 60 帧。相机以屏幕坐标限定静止区，保证自动跟随时主角留在竖屏内。地面连续格合并为条带，静态物件共用网格与材质并开启实例化；几何只在相关状态变化时更新。远处物件和人物裁剪，人物使用烘焙骨骼动画；屋顶与相机位置采用缓存，静止气泡复用轮廓。没有启用实时阴影或重型后处理。Web 使用 Cocos 的 DPR 上限 2，避免高像素比手机按 3 倍像素渲染。

桌面保持竖向画布，手机画面铺满可用区域。输入法改变可见高度时保持宽度与文字比例，草稿保留；中文选词回车继续由输入法处理。

## 本轮验收

执行一次 Cocos Web 正式构建，最终 TypeScript 检查和服务器语法检查通过。发布资源接入时修正了贴图路径、刚性帽饰节点、高 DPR 画布尺寸、脚本同步边界和透视镜头跟随范围；修正通过脚本增量同步，最后重新计算缓存版本，没有再次编译引擎。

后台 Chrome 验收涵盖：酒店点击进出与屋顶恢复、咖啡馆屋顶切换、坐姿、家具搬动和旋转、桌面杯子跟随及命中、购买入库、刷新保留进度、真实 DeepSeek 对话，以及手机尺寸、双指缩放、中文输入与键盘高度变化。场景中的活动物件都有对应模型。最后一次发布包加载没有页面异常或失败的 HTTP 请求。

390×844、设备 DPR 3 的模拟环境中，实际画布为 780×1688。咖啡馆场景采样 180 帧，平均 16.67ms，95% 分位 16.70ms，超过 33.4ms 的帧为 0，绘制调用为 50–51 次。最终街区行走另采样 218 帧，平均 16.67ms，95% 分位 16.80ms；主角横向偏离中心最多 98.67px，画布半宽为 195px。放大至 200% 后行走，最多偏离 137.85px，仍在画面内。采样来自 Mac 上的后台浏览器，不是手机真机帧率，也没有覆盖长时间运行后的发热。

证据保存在 `cocos-town3d/qa/acceptance.json`、`source-coverage.json` 和截图中。本轮没有运行自动测试套件。

# 竖屏微信预览

本轮已完成 Cocos 3D、早期 2D 网页和原生小程序的竖屏配置。Cocos 游戏、交谈、手记均按手机重新排布，浏览器试玩地址为 http://127.0.0.1:4319/。

微信小游戏工程位于 `cocos/build/wechatgame/`，压缩包为 `cocos/苔溪镇-竖屏-微信工程.zip`。这是可供开发工具导入的工程，暂未生成手机可扫描的预览二维码。

继续手机测试需要：

1. 安装微信开发者工具并由用户扫码登录。
2. 提供本项目小游戏 AppID，登录微信须拥有项目开发者权限。
3. 配置手机可访问的测试后端。当前服务器只监听本机，手机中的 127.0.0.1 指向手机自身。正式接入使用 HTTPS、合法请求域名和用户授权。
4. 导入工程，生成预览二维码，在用户手机微信中检查走动、交谈输入、手记、存档恢复以及刘海屏与键盘适配。

本轮开发工具官方下载页被浏览器安全策略阻止访问，未继续尝试绕过；已完成的浏览器验证及截图见 `cocos/qa/verification.md`。DeepSeek 凭据继续仅由本机后端读取，微信包里没有 API Key。

# Mossvale / 苔溪镇

独立 AI 小镇项目，Brizo 只提供经用户授权的 DeepSeek 配置读取；不改动 Brizo 源码、用户存档或已运行的窗口。

- 默认全程后台验证；不操作用户窗口。
- 一个请求合并修改后正式构建一次；不运行自动测试套件，除非用户要求。
- 不使用子代理，除非用户要求。
- 长篇中文交付使用 humanizer-zh，写明已实现和待实现范围。
- 地图使用内置 imagegen 原创生成，居民使用 Kenney CC0 素材，保留来源和许可。
- 人格、私有经历、印象和承诺分别保存。居民只能检索自己的记忆；印象必须有实际事件作为依据。
- 模型输出是建议，行动、时间、关系数值和存档由服务器验证并执行。
- API 密钥只存在服务端内存，由 Brizo 的既有加密存储读取；不输出、复制或写入仓库与客户端。
- 本地服务只监听 127.0.0.1。微信接入是独立客户端，正式发布前必须接入 HTTPS、登录与审核。

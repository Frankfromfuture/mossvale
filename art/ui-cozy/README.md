# 苔溪镇共用 UI 素材

2026-10-13 使用内置 imagegen 生成。当前仅接入本机 2D 网格版；像素版、两套 3D 和远程未启用。

以《月兔漫游》的温暖手绘日常物件为风格参考，采用奶油纸张、苔绿布面、暖木与黄铜细节。36 枚图标包含生活动作、物件操作、四个主要入口和导航控件；另有 6 个基础皮肤部件与 4 个独立大面板。

- `originals/`：六张 imagegen 原始 PNG，保留透明通道。
- `../../cocos-2d/assets/resources/ui-cozy/`：运行时 PNG 与 `manifest.json`，约 3 MB。图标通过矩形区域复用；大面板和小底板按九宫格拉伸，边缘比例固定。
- `../../docs/ui-cozy-prompts.json`：完整生成提示词。未调用付费 API CLI。
- `../../cocos-2d/assets/scripts/UiArt.ts`：加载、图集取图与伸缩组件；与地图几何、人物类型和服务器规则分离。
- `../../cocos-2d/assets/scripts/VillageUi.ts`：统一样式和紧凑对话组件。

运行时文件仅对原图做尺寸缩减与 PNG 编码；没有用代码重画图标。图标区域与同义动作记录在 manifest 中。文字、姓名、页码、数值和地图内容实时绘制，不烘焙到图片里。

后续接入其他表现模式时，原样复用这一素材包、字号、留白与点击规则，只适配世界坐标到屏幕坐标。UI 不随场景美术重新生成。生活记录沿用可滚动列表及原有滚动位置保留逻辑。

## 本轮验收

完成一次 Cocos Web 正式构建，TypeScript 检查通过。后台 Chrome 以 390×844 触控尺寸检查四个主要面板、PNG 动作菜单、对话发送与记录滚动；无脚本或控制台错误。像素版确认未加载新素材，仍使用原对话框。验收数据与服务端隔离，不调用模型或写入用户存档。此结果属于浏览器模拟，不代表手机真机验收。

启动时发现已有手记引擎包与 CLI 生成的组件继承格式不匹配，已把组件编译同步纳入构建收尾；同时避免旧 Babel 对 Set 展开的错误降级。最终修正已同步本机预览，没有重复执行完整构建。证据：`../../cocos-2d/qa/cozy-ui-evidence.json`。

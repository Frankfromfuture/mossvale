# 立体生活 3D

- 遵守根目录 AGENTS.md 和 design.md；后台验证，保留原有各版本。
- 本工程是当前 2D 玩法的独立 3D 客户端，不是 `cocos/` 早期 3D 的替换目录。
- 复用根目录服务器的 `cafe-2d` 规则分支。后续公共玩法修改同步检查本工程的 TownApi、TownHud、EconomyHud 与活动气泡；避免分叉服务器规则。
- 地图和物件定义由构建脚本从 2D 同步。坐标、碰撞、承载关系、账本和记忆仍由服务器决定。
- 4322、`.data-cocos-town3d/`、`mossvale_living3d` 为独立端口、存档和 Cookie。不得覆盖其他模式的数据。
- 屋顶按实际墙体分组建立，主角在建筑内隐藏，离开恢复；前景墙与树冠避免遮挡主角。屋顶隐藏不改变碰撞。
- 角色使用 Kenney CC0 原始资产，来源和修改记录在 legal/，完整原包保存在 vendor/kenney-3d/。使用烘焙骨骼动画时，刚性饰物置于骨骼根节点的同级，避免缓存停留在出生位置。
- 保持竖屏、暖木色和苔绿配色。DPR 使用 Cocos 的上限 2；设置 screen.windowSize 时乘引擎实际 DPR，避免画布缩小。
- 一个请求一次正式构建；本轮资源接入后的脚本修正通过 sync-script.mjs 同步，并由 finalize-web.mjs 更新缓存版本。后续完整构建以源码为准。
- 后台浏览器帧率和触控模拟只能作为本机开发证据，手机真机、微信导出和远程发布分别验收。
